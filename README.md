# Lun

Простая самостоятельная игра для **Luanti 5.12+** (бывший Minetest).
Без внешних зависимостей: все нужные моды лежат в `mods/`.

## Что внутри

- Пустой мир (`singlenode`): без земли, пещер и деревьев.
- Единственная стартовая платформа 9 × 9 блоков.
- Шесть строительных блоков, включая светящийся.
- Творческий режим без урона по умолчанию; права на полёт и быстрый бег.
- Автоматическое возвращение на платформу при падении ниже −30.
- Принудительная камера из-за правого плеча с автоматическим первым видом в тесноте.
- Модпак `PLAYER` с 3D-моделью игрока (см. `mods/PLAYER`).
- Мод `smart_npc`: жители с памятью, потребностями, отношениями и желаниями
  в духе Dwarf Fortress и The Sims.
- Собственные процедурно созданные текстуры 16 × 16.

## Установка

1. Скопируйте **весь репозиторий** в каталог `games/lun` пользовательских данных Luanti.
   Внутри должны оказаться `game.conf`, `minetest.conf` и папка `mods`.
   Типичные пути:
   - Linux: `~/.minetest/games/lun`;
   - Windows (переносная установка): `<папка Luanti>/games/lun`;
   - macOS: `~/Library/Application Support/minetest/games/lun`.
   Расположение может отличаться в зависимости от способа установки.
2. Перезапустите Luanti, выберите игру **Lun** и создайте **новый мир**.
3. Запустите мир. Если меняли настройки движка, проверьте, что творческий
   режим включён, а урон выключен.

Не подключайте игру к существующему миру с обычным ландшафтом:
смена генератора не удаляет уже созданные чанки.

## Управление

| Действие | Клавиша / команда по умолчанию |
| --- | --- |
| Передвижение | WASD |
| Прыжок / вверх в полёте | Пробел |
| Вниз в полёте | Shift |
| Поставить / убрать блок | ПКМ / ЛКМ |
| Инвентарь | I |
| Переключить полёт | K |
| Переключить быстрый бег | J |
| Вернуться на платформу | `/spawn` |
| Выдать отсутствующие типы блоков | `/blocks` |
| Открыть панель жителя | ПКМ по NPC без еды в руке |
| Угостить жителя | ПКМ по NPC с едой в руке |
| Поговорить с жителем | написать в чат рядом или кнопка «Поговорить» |
| Команды жителей | `/npc`, `/npc spawn`, `/npc list`, `/npc help`, `/npc build`, `/npc chop`, `/npc grove` |

Клавиши можно переназначить в настройках Luanti. Команды вводятся в чат.
`/spawn` восстанавливает отсутствующие блоки платформы, не заменяя уже
поставленные блоки. На платформе желательно оставлять свободное место
над центром: там появляется игрок.

## Структура

- `game.conf` — название и описание игры, минимальная версия Luanti.
- `minetest.conf` — настройки мира по умолчанию (`singlenode`, творческий режим).
- `mods/default/` — базовые блоки, предметы и генерация пустого мира.
- `mods/camera/init.lua` — управление камерой (смещение и переключение вида).
- `mods/creative/`, `mods/sfinv/` — творческий инвентарь и интерфейс.
- `mods/PLAYER/` — модпак с моделью и анимациями игрока (распаковано из `player_api.rar`).
- `mods/smart_npc/` — умные жители: `init.lua`, `world.lua`, `actions.lua`,
  `ui.lua`, `core/` (характер, потребности, память, желания, диалоги),
  модель, текстуры и собственный `README.md`.
- `tests/` — тесты мода без клиента. Чтобы прогнать их, выполните
  `lua tests/smart_npc_core.lua` и `lua tests/smart_npc_engine.lua`
  (или `python3 tests/run_tests.py`).

## Умные NPC

Мод `smart_npc` добавляет жителей, у которых есть пять черт характера,
семь потребностей (сытость, бодрость, общение, веселье, чистота, уют,
спокойствие), настроение и накапливающийся стресс. Жители запоминают
подарки, разговоры, удары и интересные места; сила воспоминаний со
временем падает. Память и отношения порождают желания: поблагодарить,
помириться, держаться подальше, навестить знакомое место. При долгом
истощении случается истерика.

При первом входе в мир рядом с игроком появляются два жителя. Правый
клик по жителю открывает панель с вкладками «Состояние», «Память»,
«Желания» и «Разговор». Еда в руке и правый клик — угощение. Житель
отвечает на сообщения в чате рядом с ним. Трудолюбивые жители сами рубят
деревья, добывают камень, мастерят факелы и постепенно обустраивают участок:
ставят навес, беседку, скамью, ограду или поленницу. В панели есть кнопки
«Строить», «Рубить», «Мастерить» и «Копать», а команды `/npc build [вид]`,
`/npc chop`, `/npc dig`, `/npc craft` и `/npc grove` помогают показать это
в пустом мире. Все подробности, настройки, команды
и API — в `mods/smart_npc/README.md`.

Проверки мода без клиента: `lua tests/smart_npc_core.lua`,
`lua tests/smart_npc_engine.lua` или `python3 tests/run_tests.py`.

## Автоматическая камера

Требуются **сервер и все клиенты Luanti 5.12+**: старые клиенты отключаются
с пояснением, поскольку не поддерживают принудительный режим камеры.
На открытом месте камера находится сзади, со смещением на 0,5 блока вправо
и 0,2 блока вверх (занижена для лучшего обзора, было 0,8). Первое лицо сохраняет обычную высоту глаз.
Переключение стандартной клавишей камеры заблокировано движком.

Каждые 0,1 секунды проверяется замкнутость помещения:
- по вертикали: 2 пустых блока между полом и потолком → тесно (первое лицо), 3+ → просторно;
- по горизонтали: высокие стены (высота >1, минимум 2 блока) в радиусе 2 блока по 4 направлениям X±2/Z±2 — замкнутым считается пространство с ≥2 такими стенами (коридор/комната), одиночная стена не триггерит.
Например, комната высотой 2 — тесно, 3 — просторно; коридор с высокими стенами в 2 блоках по X/Z тоже переключает в первое лицо. Низкий парапет высотой 1 не влияет. В тесноте камера мгновенно переходит в первое лицо, обратно — быстрый возврат за 0.25 сек свободы (ранее 0.8). Незагруженные участки считаются препятствиями. Настройки находятся в `mods/camera/init.lua`.

Визуальное положение камеры и удобство прицеливания следует дополнительно
проверить в клиенте при строительстве. Тесты NPC не требуют клиента и
запускаются командами из раздела «Умные NPC».
