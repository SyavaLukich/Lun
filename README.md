# Lun

Простая самостоятельная игра для **Luanti 5.12+** (бывший Minetest).
Без зависимостей от Minetest Game и сторонних модов.

## Что внутри

- Пустой мир (`singlenode`): без земли, пещер, деревьев и мобов.
- Единственная стартовая платформа 9 × 9 блоков.
- Шесть строительных блоков, включая светящийся.
- Творческий режим без урона по умолчанию; права на полёт и быстрый бег.
- Автоматическое возвращение на платформу при падении ниже −30.
- Принудительная камера сверху-за правым плечом с автоматическим первым видом в тесноте.
- Собственные процедурно созданные текстуры 16 × 16.

## Установка

1. Скопируйте **весь репозиторий** в каталог `games/lun` пользовательских данных Luanti.
   Внутри должны оказаться `game.conf`, `minetest.conf` и папка `mods`.
   Типичные пути:
   - Linux: `~/.minetest/games/lun`;
   - Windows (переносная установка): `<папка Luanti>/games/lun`;
   - macOS: `~/Library/Application Support/minetest/games/lun`.
   Расположение может отличаться в зависимости от способа установки.
2. Перезапустите Luanti, выберите игру **Lun** и создайте **новый мир**.
3. Запустите мир. Если меняли настройки движка, проверьте, что творческий
   режим включён, а урон выключен.

Не подключайте игру к существующему миру с обычным ландшафтом:
смена генератора не удаляет уже созданные чанки.

## Управление

| Действие | Клавиша / команда по умолчанию |
| --- | --- |
| Передвижение | WASD |
| Прыжок / вверх в полёте | Пробел |
| Вниз в полёте | Shift |
| Поставить / убрать блок | ПКМ / ЛКМ |
| Инвентарь | I |
| Переключить полёт | K |
| Переключить быстрый бег | J |
| Вернуться на платформу | `/spawn` |
| Выдать отсутствующие типы блоков | `/blocks` |

Клавиши можно переназначить в настройках Luanti. Команды вводятся в чат.
`/spawn` восстанавливает отсутствующие блоки платформы, не заменяя уже
поставленные блоки. На платформе желательно оставлять свободное место
над центром: там появляется игрок.

## Структура

- `game.conf` — описание игры и выбор генератора.
- `minetest.conf` — настройки мира по умолчанию.
- `mods/lun/init.lua` — блоки, платформа, инвентарь и команды.
- `mods/lun/textures/` — текстуры блоков.

## Автоматическая камера

Требуются **сервер и все клиенты Luanti 5.12+**: старые клиенты отключаются
с пояснением, поскольку не поддерживают принудительный режим камеры.
На открытом месте камера находится сзади, со смещением на 0,5 блока вправо
и 0,8 блока вверх. Первое лицо сохраняет обычную высоту глаз.
Переключение стандартной клавишей камеры заблокировано движком.

Каждые 0,1 секунды проверяются препятствия между игроком и камерой,
низкий потолок и стены с обеих сторон. При препятствии включается первый
вид; после 0,8 секунды свободного пространства возвращается третий.
Незагруженные участки считаются препятствиями. Проверка лучами учитывает
геометрию блоков; жидкости и объекты не вызывают переключение.
Настройки смещения и задержек находятся в `mods/lun/camera.lua`.

Проверки без клиента: `lua tests/smoke.lua` и `lua tests/camera.lua`
из корня репозитория. Визуальное положение и удобство прицеливания следует
дополнительно проверить в клиенте при строительстве.
