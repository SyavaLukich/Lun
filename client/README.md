# Клиент Luanti с исправленной камерой

Это патч **только для клиента** Luanti 5.18.0. Сервер и игра `Lun` не меняются,
поэтому клиент совместим с мультиплеером. Клиенты без патча продолжат
использовать старую камеру.

## Что исправляется

В `src/client/camera.cpp` третьеличная камера проверяла препятствия только
целыми шагами в 1 блок и при столкновении отступала на 0,5 блока к игроку.
В тесном месте этого недостаточно, и камера могла оказаться внутри стены.

Патч заменяет это на непрерывную проверку пути камеры с шагом 0,05 блока и
останавливает камеру за 0,15 блока до первого проходимого узла. Камера
по-прежнему остаётся в третьем лице, поэтому анимация игрока сохраняется.

Патч не меняет протокол и не требует изменений на сервере.

## Сборка

Нужен исходник Luanti точно версии **5.18.0**:

```bash
git clone --depth 1 --branch 5.18.0 https://github.com/luanti-org/luanti.git
cd luanti
git apply /path/to/Lun/client/luanti-5.18.0-camera-collision.patch
```

Дальше используется обычная сборка Luanti:

- **Windows** — официальная инструкция `doc/compiling/windows.md` (MSVC + vcpkg
  или MinGW). Для MinGW в CI используется `util/buildbot/buildwin64.sh`.
- **Android** — официальная инструкция `doc/compiling/android.md`
  (Android Studio/NDK, затем `./gradlew assembleDebug` или `assembleRelease`).
- **Linux** — `cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build`.

APK для Android должен быть подписан. Debug-сборка (`assembleDebug`)
подписывается автоматически debug-ключом и подходит для установки вручную.

## Готовые сборки

В репозитории есть workflow `.github/workflows/build-client.yml`. Он собирает
патченный клиент для Windows x64 и Android и складывает результаты в
Artifacts соответствующего запуска GitHub Actions.

## Ограничения

- Патч рассчитан на Luanti **5.18.0**; для другой версии контекст
  `src/client/camera.cpp` может отличаться.
- Все игроки, которым нужна исправленная камера, должны запускать патченный
  клиент.
- Если стена находится ближе near-plane камеры, полностью убрать клиппинг
  на уровне клиента всё равно нельзя — но камера больше не будет уходить
  внутрь стены на грубые полблока.
